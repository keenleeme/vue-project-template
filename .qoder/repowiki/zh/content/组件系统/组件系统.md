## 组件元数据索引

`das-component-vue.json` 文件作为组件库的元数据索引，集中管理所有UI组件的分类、描述和使用场景信息。该文件采用结构化JSON格式，按功能类别组织组件，便于开发者快速查找和理解组件用途。

文件结构包含以下核心字段：
- `name`: 组件库名称
- `description`: 组件库描述
- `version`: 当前版本号
- `totalComponents`: 组件总数
- `categories`: 按功能分类的组件集合

每个组件条目包含：
- `id`: 组件唯一标识符
- `name`: 组件中文名称
- `description`: 组件功能描述
- `whenToUse`: 使用场景说明

该元数据文件为组件库提供了统一的索引机制，支持自动化文档生成和开发工具集成。

## 组件文档说明

组件详细使用说明通过Markdown文件提供，存放于 `das-components-folder/docs` 目录下。每个组件对应一个独立的 `.md` 文件，采用统一的文档结构，包含以下核心部分：

### 组件说明
描述组件的基本功能和设计目的，说明其在系统中的角色和价值。

### 何时使用
明确组件的适用场景和最佳实践，帮助开发者判断是否适合当前需求。

### 交互演示
提供可运行的代码示例，通过 `:::demo` 代码块展示组件的实际效果和配置方式。

### 功能示例
分场景展示组件的不同用法，如基础用法、高级配置、特殊场景等。

### API文档
以表格形式列出组件的Props、Events、Slots等接口信息，包含参数名称、类型、默认值和说明。

### 注意事项
记录使用组件时需要注意的特殊行为或限制条件。

文档中还包含设计指导和落地实践建议，确保组件在不同场景下的一致性。

## 组件开发规范

以 `layout/index.vue` 为例，展示组件开发的标准化实践。该组件作为系统布局容器，体现了典型的Vue 3组合式API使用模式。

### Props定义
组件通过 `defineProps` 定义接收的属性，但在本例中主要使用响应式数据和计算属性。

### 事件通信
使用 `emits` 定义触发的事件，本组件主要通过路由变化和状态更新实现通信。

### 插槽使用
组件通过 `<RouterView>` 和其他子组件实现内容分发，支持灵活的页面布局。

### 状态管理
集成Pinia状态管理，通过 `storeToRefs` 订阅主题、菜单和应用状态。

### 响应式处理
使用 `watchEffect` 和 `watch` 监听路由和状态变化，动态更新组件行为。

### 样式控制
通过动态class绑定实现主题切换和布局调整，支持暗色模式和多种布局风格。

该组件展示了如何将业务逻辑与UI分离，通过配置对象 `menuConfig` 实现菜单数据的集中管理。

## 组件引入与使用

### 异步按钮 (das-async-button)
用于需要状态反馈的操作场景，如数据导出、连通性测试等。

```vue
<das-async-button status="loading">测试中</das-async-button>
```

支持五种状态：禁用、默认、加载、成功、失败，通过状态流转提供即时反馈。

### 表单组件 (das-form)
提供灵活的表单布局方案，支持水平、垂直、行内等多种布局方式。

```vue
<das-form :model="formState" :rules="rules" @finish="onFinish">
  <das-form-item label="名称" name="name" required>
    <a-input v-model:value="formState.name" />
  </das-form-item>
</das-form>
```

支持表单分组、导航锚点、互斥显示等高级功能。

### 表格组件 (das-table)
功能强大的数据展示组件，支持自定义刷新、一键折叠、列设置等功能。

```vue
<das-table :columns="columns" :data-source="dataSource" row-key="id">
  <template #bodyCell="{ column, record }">
    <div v-if="column.dataIndex === 'age'">{{ record.age }}</div>
  </template>
</das-table>
```

提供丰富的插槽支持，包括操作项、快捷查询、自定义表头等。

### 按钮组 (das-button-group)
统一管理相关操作按钮，支持多种使用场景。

```vue
<das-button-group type="form" form-type="edit" />
<das-button-group type="table" :actions="actions" :has-selection="hasSelection" />
```

### 自动标签更多 (das-auto-tag-more)
在空间有限时自动隐藏部分标签并显示"更多"按钮。

```vue
<das-auto-tag-more :tags="tagList" :tagGap="8" :moreGap="4" />
```

### 文字滚动 (das-carousel)
实现简单的文字或图片滚动效果。

```vue
<das-carousel :height="20" :width="300" :speed="1.5">
  <p>滚动文字内容</p>
</das-carousel>
```
