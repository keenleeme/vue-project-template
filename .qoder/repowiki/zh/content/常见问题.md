## 环境配置问题

### TypeScript类型错误
当出现TypeScript类型错误时，首先检查`tsconfig.json`文件中的配置是否正确。本项目中，`tsconfig.json`配置了严格的类型检查选项，如`"strict": true`，这可能导致一些隐式类型的代码报错。确保所有变量和函数参数都有明确的类型声明。

**解决方案**：
- 检查并修正类型声明。
- 如果需要，可以在`tsconfig.json`中调整`"noImplicitAny"`等选项。

```json
{
```

### 自动导入失效
自动导入功能由`unplugin-auto-import`插件提供，其配置位于`vite.config.base.ts`中。如果自动导入失效，请检查`auto-imports.d.ts`文件是否正确生成，并且`vite.config.base.ts`中的`AutoImport`插件配置是否正确。

**解决方案**：
- 确保`AutoImport`插件已正确安装。
- 检查`auto-imports.d.ts`文件内容是否包含所需的导入。

```typescript
AutoImport({
  imports: ['vue', 'vue-router'],
  dts: './auto-imports.d.ts',
  eslintrc: {
    enabled: false,
    filepath: './.eslintrc-auto-import.json',
    globalsPropValue: true
  },
  vueTemplate: false
})
```

## 构建失败问题

### Vite插件冲突
Vite插件冲突可能导致构建失败。例如，`vite-plugin-compression`和`vite-plugin-imagemin`可能与其他插件产生冲突。检查`vite.config.prod.ts`中的插件配置，确保没有重复或冲突的插件。

**解决方案**：
- 禁用不必要的插件。
- 检查插件版本兼容性。

```typescript
import { mergeConfig } from 'vite';
import compressPlugin from 'vite-plugin-compression';
import configImageminPlugin from './plugin/imagemin';
import baseConfig from './vite.config.base';

export default mergeConfig(
  {
    mode: 'production',
    plugins: [
      compressPlugin({
        ext: '.gz'
      }),
      configImageminPlugin()
    ],
    build: {
      rollupOptions: {
        output: {
          manualChunks: {
            vue: ['vue', 'vue-router', 'pinia']
          }
        }
      },
      chunkSizeWarningLimit: 2000
    }
  },
  baseConfig
);
```

### 资源加载异常
资源加载异常通常与路径配置有关。检查`vite.config.base.ts`中的`resolve.alias`配置，确保别名正确指向目标路径。

**解决方案**：
- 确认`alias`配置正确。
- 检查资源文件路径是否正确。

```typescript
resolve: {
  alias: [
    {
      find: '@',
      replacement: resolve(__dirname, '../src')
    },
    {
      find: 'vue',
      replacement: 'vue/dist/vue.esm-bundler.js' // compile template
    }
  ],
  extensions: ['.ts', '.js']
}
```

## 微前端通信故障

### 通信机制
微前端通信通过`@micro-zoe/micro-app`库实现。基座应用可以通过`setData`、`getData`等方法与子应用进行数据交换。子应用也可以通过`microApp.addDataListener`监听基座应用的数据变化。

**解决方案**：
- 确保`microApp`已正确初始化。
- 检查数据监听函数是否正确注册。

```typescript
export function setData(appName: string, data: microData): void {
  microApp.setData(appName, data);
}

export function getData(appName: string): microData | null {
  return microApp.getData(appName);
}

export function microAppAddDataListener(appName: string, dataListener: CallableFunction, autoTrigger?: boolean): void {
  microApp.addDataListener(appName, dataListener, autoTrigger);
}
```

## 路由守卫异常

### 路由保护机制
路由守卫通过`vue-router`的`beforeEach`钩子实现。在`src/router/guard.ts`中定义了全局前置守卫，用于检查用户权限和登录状态。

**解决方案**：
- 确保`setupPermissionGuard`函数已正确调用。
- 检查白名单路径是否正确配置。

```typescript
export const WHITE_LIST: string[] = ['/404', '/login', '/ai-agent'];

export function setupPermissionGuard(router: Router) {
  router.beforeEach(async (to, _, next) => {
    const userStore = useUserStore();
    if (to.query) {
      const { code, state } = to.query;
      if (code && state === 'relogin') {
        const res = await fetchDingTalkUserInfo(code as string);
        if (res.code === 200) {
          const { data } = res;
          const { accessToken, user } = data;
          userStore.setToken(accessToken);
          userStore.setUserInfo(user);
        }
      }
    }
    const appStore = useAppStore();
    const menusStore = useMenusStore();
    if (to.path !== '/themeConfig') {
      appStore.setThemePanelVisible(false);
    }
    if (WHITE_LIST.includes(to.path)) {
      if (to.path === '/login' && userStore.token) {
        next({ path: '/' });
      }
      next();
    } else if (userStore.token) {
      if (!menusStore.menusData.length) {
        const menusData = await getMenus();
        menusStore.setMenus(menusData);
      }
      if (!userStore.permissionIds.length) {
        const permissionIds = await getPermissions();
        userStore.setPermissionIds(permissionIds);
      }
      if (to.path === '/') {
        const firstMenu = menusStore.findFistSiderMenu();
        if (firstMenu && firstMenu.path) {
          next(firstMenu.path);
          return;
        }
        next('/404');
        return;
      }
      if (!userStore.permissionIds.includes(to.meta.permissionId as string) && !to.meta.public) {
        next('/404');
        return;
      }
      next();
    } else {
      next({
        path: '/login'
      });
    }
  });
}
```

## 主题切换不生效

### 主题管理机制
主题切换通过`src/theme/themeAlgorithm.ts`中的`themeAlgorithm`函数实现。该函数监听`themeConfig`的变化，并动态更新CSS变量。

**解决方案**：
- 确保`themeAlgorithm`函数已正确调用。
- 检查`themeConfig`的`mode`和`primaryColor`是否正确更新。

```typescript
const themeAlgorithm = () => {
  let primaryColors: string[] = [];
  let darkPrimaryColors: string[] = [];
  const themeStore = useThemeStore();
  const { themeConfig } = storeToRefs(themeStore);
  const config = ref({
    ...themeConfig.value
  });
  watchEffect(() => {
    config.value = { ...themeConfig.value };
  });

  watch(
    () => config.value.primaryColor,
    () => {
      const color = Color(config.value.primaryColor);
      const darkOriginColor = color
        .saturate(15 / 85)
        .lighten(0.3)
        .hex();
      primaryColors = generate(config.value.primaryColor);
      darkPrimaryColors = generate(darkOriginColor, { theme: 'dark', backgroundColor: '#1c222e' });
      nextTick(() => {
        const bodyEl = document.body;
        bodyEl.style.setProperty('--um-primary-color-light', primaryColors[0]);
        bodyEl.style.setProperty('--um-primary-color-hover', primaryColors[4]);
        bodyEl.style.setProperty('--um-primary-color-normal', primaryColors[5]);
        bodyEl.style.setProperty('--um-dark-primary-color-light', darkPrimaryColors[0]);
        bodyEl.style.setProperty('--um-dark-primary-color-hover', darkPrimaryColors[4]);
        bodyEl.style.setProperty('--um-dark-primary-color-normal', darkPrimaryColors[5]);
        bodyEl.style.setProperty('--c-color-primary-7', primaryColors[7]);
        bodyEl.style.setProperty('--c-color-primary-5', primaryColors[4]);
        bodyEl.style.setProperty('--c-color-primary-6', primaryColors[5]);
        bodyEl.style.setProperty('--c-color-primary-2', primaryColors[1]);
        bodyEl.style.setProperty('--d-color-primary-7', darkPrimaryColors[7]);
        bodyEl.style.setProperty('--d-color-primary-5', darkPrimaryColors[4]);
        bodyEl.style.setProperty('--d-color-primary-6', darkPrimaryColors[5]);
        bodyEl.style.setProperty('--d-color-primary-2', darkPrimaryColors[1]);
        bodyEl.style.setProperty('colorPrimary', primaryColors[0]);
        bodyEl.style.setProperty(
          '--um-font-size',
          window.getComputedStyle(document.documentElement).getPropertyValue('--font-size-base')
        );
      });
    },
    {
      immediate: true,
      deep: true
    }
  );

  watch(
    () => config.value.mode,
    (val) => {
      const bodyEl = document.body;
      bodyEl.className = val === 'dark' ? 'theme-dark' : 'theme-light';
    },
    { immediate: true }
  );
};
export default themeAlgorithm;
```
