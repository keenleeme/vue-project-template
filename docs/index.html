📋 项目概述

这是一个基于微前端架构的 Vue 项目，包含多个独立的子应用，支持：

🎯 微前端架构

支持 Vue2、Vue3、React、Angular 等多种框架的子应用

🔧 Docker 部署

使用 Docker 容器化部署，简化运维流程

🌐 Nginx 反向代理

统一路由管理，支持子应用独立访问

📱 响应式设计

支持PC端和移动端，提供良好的用户体验

🗺️ 访问路径

  • 主应用： /
  • Vue2 子应用： /subapp/vue2/
  • Vue3 子应用： /subapp/vue3/
  • React 子应用： /subapp/react/
  • Angular 子应用： /subapp/angular/
  • 帮助文档： /docs/
  • API 接口： /api/*

🚀 快速开始

# 克隆项目
git clone <repository-url>

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# Docker 部署
docker-compose up -d --build

🔧 技术栈

  • 主框架： Vue 3 + TypeScript
  • 构建工具： Vite
  • UI 框架： Ant Design Vue
  • 状态管理： Pinia
  • 路由： Vue Router
  • 微前端： qiankun
  • 容器化： Docker + Nginx
