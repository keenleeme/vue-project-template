### 档案管理
> 📁 **文件**: [archive-management/](mdc:pages/archive-management.md)  
> 🎯 **用途**: 数据处理者档案管理系统

**核心功能**:
- 多条件组合搜索 (区域、组织架构、名称、行业等)

### 应用系统管理
> 📁 **文件**: [applicationSystem/](mdc:pages/application-system.md)  
> 🎯 **用途**: 应用系统信息统一管理，包括系统注册、详情管理、风险评估和统计分析

**核心功能**:
- 多维度搜索筛选 (系统名称、类型、等级、组织架构等)
- 数据统计可视化 (风险概况、系统类型分布、等级分布)
- 双视图模式展示 (系统卡片视图和管理表格视图)
- 系统信息管理 (新增、编辑、删除、查看详情)
- 批量操作功能 (导出、扫描、删除)

**技术特点**:
- 高度组件化设计，8个功能组件
- 三段式布局：搜索 + 统计图表 + 双视图展示
- 支持路由跳转到新增/编辑/详情页面

### 表资产管理
> 📁 **文件**: [tableAssetManage/](mdc:pages/table-asset.md)  
> 🎯 **用途**: 数据表元数据管理，包括表结构信息维护、字段元数据管理、数据血缘关系

**核心功能**:
- 表资产信息管理 (表名、所属数据库、表类型、创建时间等)
- 表字段元数据管理 (字段名、数据类型、长度、主键、索引等)
- 元数据同步功能 (从数据库系统自动同步表结构)
- 数据血缘关系管理 (追踪数据来源和流向)
- 表资产搜索筛选 (多维度搜索和筛选)

**技术特点**:
- 超大页面(44KB)，双层数据管理(表级+字段级)
- 复杂的数据库连接和同步逻辑
- 支持数据血缘关系图表展示

## 🔧 使用说明

### 快速定位页面
1. **按功能分类查找**: 从上方分类表格快速定位
2. **按文件路径查找**: 根据 `src/views/` 下的目录结构
3. **按技术特点查找**: 根据实现技术和复杂度

### 修改页面时的流程
1. **查找对应页面**: 使用本索引定位功能文件
2. **了解功能详情**: 查看对应的详细功能描述
3. **定位修改位置**: 根据功能模块定位到具体文件
4. **更新索引**: 修改完成后及时更新功能描述

### 新增页面时的流程
1. **创建功能描述**: 在 `pages/` 目录下创建对应的功能描述文件
2. **更新索引**: 在本文件中添加新页面的索引信息
3. **选择参考模板**: 根据页面类型选择合适的设计模板
