## 简介

`blockCard` 是一个通用的卡片容器组件，位于 `src/components/uedModule/blockCard/index.vue`。该组件封装了标准的卡片布局结构，包含标题区域、操作区和内容区，广泛应用于列表页、详情页和仪表盘等界面中，用于统一 UI 风格并提升开发效率。

该组件通过 `props` 提供灵活的配置选项，支持自定义标题、边框样式、内边距和两列布局；通过 `slot` 机制实现内容的灵活嵌入，能够承载表单、图表、列表等多种内容类型。其设计遵循模块化和可复用原则，是项目中构建一致视觉体验的核心组件之一。

## 核心功能与结构

`blockCard` 组件采用 Vue 3 的 `<script setup>` 语法，结合 TypeScript 实现类型安全。其核心功能是提供一个结构清晰、样式统一的容器，用于组织页面中的功能模块。

### 组件结构解析

组件的模板结构分为三个主要部分：

1. **标题区域（Header）**：包含主标题、描述性文字和操作按钮。
2. **内容区域（Content）**：承载主要业务内容，支持单列或双列布局。
3. **样式控制**：通过 CSS 变量和类名动态控制外观。

```vue
<template>
  <div class="block-card" :class="{ 'top-border': topBorder }">
    <!-- 标题与操作区 -->
    <div class="block-card-header" :class="{ 'title-border': topBorder || titleBorder }">
      <h2>{{ title }}</h2>
      <div class="block-card-description"><slot name="description" /></div>
      <div class="block-card-ops">
        <slot name="operation" />
        <a-button v-show="more" type="link"> {{ $t('I18N.layout.gengDuo') }} </a-button>
      </div>
    </div>
    <!-- 内容区 -->
    <div class="block-card-content" :class="{ 'two-columns': twoColumns }" :style="contentPaddingStyle">
      <slot name="content"><slot /></slot>
    </div>
  </div>
</template>
```

## Props 配置项详解

`blockCard` 组件通过 `defineProps` 定义了多个配置项，允许父组件对其进行高度定制。

| Prop 名称 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| `title` | `String` | 必填 | 卡片的主标题，显示在左上角 |
| `more` | `Boolean` | `false` | 是否显示“更多”链接按钮 |
| `topBorder` | `Boolean` | `false` | 是否显示顶部边框 |
| `titleBorder` | `Boolean` | `false` | 是否在标题区域下方显示分隔线 |
| `twoColumns` | `Boolean` | `false` | 内容区是否启用两列布局 |
| `contentPadding` | `[Number, String]` | `0` | 内容区的内边距，支持像素值或字符串（如 '16px'） |

### 计算属性 `contentPaddingStyle`

该属性将 `contentPadding` prop 转换为 CSS 样式对象，支持数字和字符串两种输入方式：

```ts
const contentPaddingStyle = computed(() => {
  const padding = typeof props.contentPadding === 'number' ? `${props.contentPadding}px` : props.contentPadding;
  return padding ? { padding } : undefined;
});
```

此设计提高了 API 的灵活性，开发者可以传入 `16` 或 `'16px'`，组件都能正确处理。

## 插槽（Slot）机制说明

`blockCard` 组件通过命名插槽（Named Slots）实现内容的高度可定制化，支持以下插槽：

### `description` 插槽
位于标题右侧，用于显示对当前模块的简要说明。通常用于补充标题信息。

**示例：**
```vue
<template #description>
  <span class="head-description">（{{ $t('I18N.layout.peiZhiMiMaAnQuanYaoQiu') }}）</span>
</template>
```

### `operation` 插槽
位于标题区域最右侧，用于放置操作按钮，如“刷新”、“导出”等。

**示例：**
```vue
<template #operation>
  <a-button @click="refresh">刷新</a-button>
</template>
```

### `content` 插槽
卡片的主要内容区域。若未指定 `content` 插槽，则默认插槽生效，允许直接嵌入内容。

**示例：**
```vue
<template #content>
  <div ref="pieChart1" class="chart-container"></div>
</template>
```

## 样式与布局控制

组件使用 Less 编写样式，并通过 CSS 变量实现主题化支持，确保与项目整体设计系统保持一致。

### 核心样式类

```less
.block-card {
  background: var(--color-bg-container);
  &.top-border {
    border-top: 1px solid var(--color-component-stroke);
  }
  .block-card-header {
    &.title-border {
      border-bottom: 1px solid var(--color-component-stroke);
    }
  }
  .block-card-content {
    &.two-columns {
      display: flex;
      flex-direction: row;
      & > div {
        width: 50%;
      }
    }
  }
}
```

- `--color-bg-container`：卡片背景色
- `--color-component-stroke`：边框颜色
- `--color-text-primarys`：文本主色

### 响应式布局
当 `twoColumns` 为 `true` 时，内容区使用 `flex` 布局，子元素均分宽度，适用于表单等需要并排显示的场景。

## 实际使用场景示例

`blockCard` 组件在多个页面中被广泛使用，以下是三个典型场景的分析。

### 1. 仪表盘（工作台） - 图表容器

在 `workBench/components/charts.vue` 中，`blockCard` 被用作 ECharts 图表的容器，每个卡片展示一种数据视图。

```vue
<BlockCard :title="$t('I18N.layout.woFuZeShiJianDeJiBieFenPei')">
  <template #content>
    <div ref="pieChart1" class="chart-container"></div>
  </template>

```

此用法体现了组件作为“数据可视化容器”的角色，通过统一的标题和边框，使多个图表在视觉上形成有机整体。

### 2. 配置页面 - 表单布局

在 `baseConfig/index.vue` 中，`blockCard` 用于组织表单配置项，启用 `twoColumns` 和 `contentPadding` 实现美观的表单布局。

```vue
<BlockCard
  :title="$t('I18N.layout.miMaAnQuanSheZhi')"
  :two-columns="true"
  :title-border="true"
  :content-padding="24"
>
  <template #description>
    <span class="head-description">（{{ $t('I18N.layout.peiZhiMiMaAnQuanYaoQiu') }}）</span>
  </template>
  <div class="content">
    <div class="content-row">
      <span>最小密码长度</span>
      <a-input-number v-model:value="minPasswordLen" />
      <span>位，最大密码长度</span>
      <a-input-number v-model:value="maxPasswordLen" />
      <span>位</span>
    </div>
  </div>
</BlockCard>
```

此场景展示了组件在复杂表单中的布局能力，`two-columns` 结合 `content-row` 实现了灵活的表单项排列。

此用法突出了组件的“模块化”特性，将相关功能聚合在一个视觉单元内，提升页面的可读性和可维护性。

## 最佳实践与 UI 统一性

`blockCard` 组件是实现项目 UI 统一性的关键。通过以下最佳实践，可以最大化其价值：

1. **一致性**：所有功能模块均应包裹在 `blockCard` 中，确保标题、边框、内边距等样式统一。
2. **语义化使用**：合理使用 `description` 和 `operation` 插槽，增强界面的信息层次。
3. **主题适配**：依赖 CSS 变量而非硬编码颜色，确保在深色/浅色主题下均能正确显示。
4. **国际化支持**：标题使用 `$t()` 进行国际化，如 `$t('I18N.layout.miMaAnQuanSheZhi')`，确保多语言环境下的可用性。

通过在列表页、详情页和仪表盘中统一使用 `blockCard`，项目实现了高度一致的视觉语言，降低了用户的认知成本，同时提高了前端开发的效率和代码的可维护性。
